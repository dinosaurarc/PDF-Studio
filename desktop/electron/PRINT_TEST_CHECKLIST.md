# PDF大编辑桌面端打印测试清单

版本发布前请在 Windows 和 macOS 各跑一遍。测试时不要把临时 PDF、日志、安装包或打印输出文件提交到 GitHub Code 页面。

## Windows

- 使用 Microsoft Print to PDF。
- 使用至少一台真实打印机，或系统中可模拟的打印机。
- 普通“打印”只出现 PDF大编辑内部打印中心，不自动弹出浏览器打印预览或第二个系统窗口。
- 点击“系统高级打印……”时，才出现系统或厂商驱动打印窗口。

## macOS

- 使用系统打印功能。
- 使用“存储为 PDF”。
- 普通“打印”只出现 PDF大编辑内部打印中心，不自动弹出浏览器打印预览或第二个系统窗口。
- 点击“系统高级打印……”时，才出现系统打印窗口。

## 文档与页面

- 1 页 PDF。
- 100 页以上 PDF。
- 删除、旋转、排序后的 PDF。
- 加入文字、图形、涂鸦、直线后的 PDF。
- 图片拖入后转换为 PDF 页面的文档。

## 页面范围

- 全部页面。
- 当前页。
- 当前选中的页面。
- 自定义：`1-3`。
- 自定义：`1,3,5`。
- 自定义：`1-3,6,8-10`。
- 非法范围：空输入、超出页数、重复页、倒序范围。

## 打印设置

- A4 与 Letter。
- 纵向、横向、自动匹配页面方向。
- 彩色与灰度。
- 单面、长边翻转、短边翻转。
- 多份和逐份打印。
- 适合页面、实际大小、自定义百分比。
- 每张纸 1、2、4 页。
- 默认页边距、无页边距、自定义毫米页边距。

## 异常与稳定性

- 无打印机时显示易懂提示。
- 打印机离线或不可用时显示清楚错误。
- 用户取消系统高级打印时不崩溃。
- 打印过程中连续点击“打印”不会重复提交。
- 关闭打印中心后不残留临时窗口。
- 预览内容与实际打印内容来自同一份当前编辑后的临时 PDF。
