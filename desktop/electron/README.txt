PDF大编辑 0.3.4 桌面软件

系统要求：
- Windows 10 或 Windows 11，64 位系统。
- macOS 12 或更高版本。

安装版：
- 运行文件名中带 Setup 的 EXE。
- 可以选择安装位置，并会创建开始菜单和桌面快捷方式。
- 安装后会出现在 PDF 的“打开方式”中，双击 PDF 可直接打开对应文件。
- 再次运行新版安装包即可覆盖更新，原来的快捷方式和文件关联会继续使用。
- 安装版可在“更多 > 检查更新”中下载并重启安装新版。
- 可在 Windows“设置 > 应用”中干净卸载。

免安装版：
- 运行文件名中带 Portable 的 EXE。
- 不需要安装，删除 EXE 即可卸载。
- 免安装版不会注册 PDF 打开方式。
- 免安装版只提示新版，不会自动安装更新。

macOS：
- GitHub Release 同时提供 DMG 安装包和用于自动更新的 ZIP。
- 从 DMG 将软件拖入“应用程序”后使用。
- 完整自动更新需要发布包使用 Apple Developer ID 签名。

打开文件：
- 软件使用单实例运行。连续双击多个 PDF 时，会在同一个软件窗口中打开多个标签页。
- “打开”按钮会把 PDF 打开为新标签页；拖入 PDF 会追加到当前文档。

保存与关闭：
- “保存”优先覆盖打开时选择的源 PDF。
- 关闭有改动的文件或退出软件时，会询问“保存 / 不保存 / 取消”。
- “保存”会完成保存后退出，“不保存”会直接退出，“取消”会留在软件中。

打印：
- 桌面版点击“打印”会打开软件内部打印中心。
- 普通“打印”会直接发送到所选系统打印机，不再自动弹出浏览器打印预览或第二个系统窗口。
- “系统高级打印……”用于纸盒、装订、安全打印等厂商专有选项。

说明：
- 软件中的 PDF 和图片在本机处理，不会自动上传网络。
- PDF 转 Word 也在本机完成，不需要上传文件。
- 未购买 Windows 代码签名证书前，Windows 可能显示“未知发布者”提示。
