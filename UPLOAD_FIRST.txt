PDF Studio - GitHub 网页上传说明

1. 在 Mac 上按 Command + Shift + . 显示隐藏文件。
2. 打开本文件夹，确认能看到 .github 文件夹。
3. 在 GitHub 仓库网页点击 Add file -> Upload files。
4. 把本文件夹里面的全部内容拖到上传页面。
5. 不要上传这个 ZIP 本身，也不要只拖最外层文件夹。
6. 上传完成后点击 Commit changes。
7. 点击仓库顶部 Actions，等待 Build Windows application 变成绿色对勾。
8. 打开成功的记录，在页面底部 Artifacts 下载 PDF-Studio-Windows。

说明：
- .github 是正常的隐藏文件夹名称，不是乱码。
- Setup.exe 是安装版；Portable.exe 是免安装版。
